## 🔭 Key Projects

1.  **RAG Pipeline Evaluator**
    * **Description:** End-to-end RAG evaluation platform using dual LLM judges (Gemini and Groq/Llama) for A/B testing between RAG pipelines across faithfulness, retrieval, and generation metrics. Includes a retrieval evaluation module with query expansion and Precision@K/Recall@K, and a generation quality layer scoring faithfulness and hallucination rates.
    * **Technologies:** FastAPI, React, MongoDB, LLM-as-a-Judge, pytest, Playwright, Oracle Cloud.

2.  **ClearAudit (Agentic Expense Review)**
    * **Description:** An agentic expense/transaction review system with human-in-the-loop escalation and full audit logging. A LangGraph pipeline classifies each claim, produces an explicit confidence score, and either auto-approves or routes it to a human reviewer through a Redis-backed queue, with every decision written to an immutable audit trail.
    * **Technologies:** FastAPI, LangGraph, PostgreSQL, Redis, React/Vite, deployed on Railway and Vercel.

3.  **Hybrid arXiv Paper Search**
    * **Description:** A hybrid semantic + keyword search engine over live-fetched arXiv abstracts, combining vector search (Qdrant, sentence-transformers) with BM25 keyword search, merged via Reciprocal Rank Fusion. Evaluated against 20 hand-labeled queries; the hybrid approach outperformed either method alone on every metric measured (Recall@10 of 0.942 and MRR of 0.917, versus ~0.85 and ~0.75 for vector or BM25 alone).
    * **Technologies:** Qdrant, sentence-transformers, rank_bm25, FastAPI.

4.  **AJT Surgicals Buyer Discovery Agent**
    * **Description:** An agentic AI system automating buyer discovery for a surgical instruments export business, orchestrating multi-step workflows across tools and APIs.
    * **Technologies:** Groq (Llama 3.1), FastAPI, React, Docker.

5.  **Advanced Language Model Development (SmolLM)**
    * **Description:** A Llama3-based language model built from scratch, implementing core architectural components (RMSNorm, RoPE, GQA, SwiGLU FFN), with parameter-efficient fine-tuning via LoRA and preference alignment via Direct Preference Optimization (DPO).
    * **Technologies:** Python, PyTorch, Transformers.

6.  **Fine-Grained Deer Species Classification**
    * **Description:** A deep learning pipeline for fine-grained classification of visually similar deer species from the Missouri Camera Traps dataset, reaching 95.71% test accuracy using CLIP feature extraction and a stacking ensemble (MLP + XGBoost), outperforming a ResNet50 baseline.
    * **Technologies:** Python, PyTorch, TensorFlow, Scikit-learn, OpenCV, CLIP, XGBoost.

7.  **Urdu News Categorization System**
    * **Description:** A system to categorize unstructured Urdu-language news, with a scraped dataset and comparison of SVM, Multinomial Naive Bayes, and Neural Network models, reaching over 93% accuracy.
    * **Technologies:** Python, Scikit-learn, Pandas, NumPy, Selenium, NLP.

8.  **Foundational Full-Stack Projects**
    * **Description:** CulinaryCloud, a MERN recipe-sharing platform with AI-driven recommendations, and ColorGrid, a real-time 2-player game built with Socket.IO for live matchmaking and synchronized gameplay.
    * **Technologies:** MERN Stack, Socket.IO, JavaScript, Selenium.
