## 🔭 Key Projects

Here are some of the projects I'm proud to have worked on:

1.  **Advanced Language Model Development & Optimization (SmolLM)**
    * **Description:** Developed "SmolLM," a Llama3-based language model from scratch, implementing core architectural components (RMSNorm, RoPE, GQA, SwiGLU FFN). Engineered parameter-efficient fine-tuning using Low-Rank Adaptation (LoRA) and aligned the model with human preferences via Direct Preference Optimization (DPO).
    * **Technologies:** Python, PyTorch, Transformers, NLP.

2.  **Fine-grained Classification of Deer Species** 
    * **Description:** Engineered a deep learning pipeline for fine-grained classification of four visually similar deer species from the Missouri Camera Traps dataset. Achieved 95% test accuracy using OpenAI's CLIP model for feature extraction and a stacking ensemble classifier (MLP & XGBoost), outperforming a ResNet50 baseline. Addressed class imbalance with Focal Loss and evaluated model robustness against synthetic noise
    * **Technologies:** Python, PyTorch, TensorFlow, Scikit-learn, OpenCV, CLIP, XGBoost.

3.  **CulinaryCloud (Recipe Sharing Platform)** 
    * **Description:** Contributed to the development of a full-stack MERN (MongoDB, Express.js, React, Node.js) web application for interactive recipe sharing. Features included user management, recipe uploads, AI-powered personalized recommendations, nutritional analysis, and social interactions. Involved in comprehensive testing, including manual BlackBox and automated Selenium tests.
    * **Technologies:** MERN Stack (MongoDB, Express.js, React, Node.js), JavaScript, HTML, CSS, Selenium, Git.

4.  **ColorGrid (Real-Time 2-Player Game)** 
    * **Description:** Developed a 2-player, turn-based color conquest game using the MERN stack and Socket.IO for real-time communication. Implemented complete game logic, user authentication, real-time matchmaking, synchronized gameplay, game history, user profiles, a coin-based economy, and a searchable leaderboard.
    * **Technologies:** MERN Stack (MongoDB, Express.js, React, Node.js), Socket.IO, JavaScript.

5.  **Urdu News Categorization System** 
    * **Description:** Developed a personalized system to categorize unstructured Urdu-language news. Curated a dataset by scraping articles (using Selenium) implemented comprehensive preprocessing, and compared SVM, Multinomial Naive Bayes, and Neural Network models, achieving over 93% accuracy with MNB.
    * **Technologies:** Python, Scikit-learn, Pandas, NumPy, Selenium, NLP.
